# All recipes

The Comment "Delegate what you can check: ten lessons on AI agents in research" distils what about 30 group leaders at the Helmholtz Munich Computational Health Center learned from a year of using agents.
Each of its points is written up here as a recipe, with the steps, how to check the output and the errors reported so far.
The list grows as other groups add recipes.
The recipes follow the order in which a group meets them: preparing for agents, thinking with them and implementing with them.

## The rule behind them

Hand agents the work whose results can be checked cheaply, and put effort into making more of your research checkable.
[Delegate by verifiability](../guide/verifiability.md) explains the rule.
Some work stays with people even when checking is cheap: see [Where to draw the line](../guide/limits.md).

## Tried a recipe?

Each recipe has a discussion thread at the bottom.
An example from a second group changes a recipe's status from **tried** to **reproduced**.
See [Contribute](../about/contribute.md).
