## Summary

Agents do formatting and consistency work well.
The author writes the arguments and makes the judgments.

## Steps

1. Check the manuscript against the journal's guidelines before submission.
   Editors and reviewers may run the same check.
2. Write reviews and reports from your own bullet points, and give the agent an example of your writing.
3. Make notation and references consistent across long documents, and replace preprint citations with the published versions.
4. Use agents to build teaching material: interactive visualizations, tutorials and flashcards.

## How to check the output

The author reads every sentence that goes out under their name.
A script can check formatting.
Only a person can check an argument.

## Examples

- In a textbook with many authors, an agent made the notation and bibliography consistent and replaced preprint citations with published versions.
- A large lecture was converted to a text-based slide format that an agent can edit.
- Teaching uses included interactive HTML visualizations, tutorials and flashcards for spaced repetition.

## Known problems

- A thesis review drafted by an agent was almost identical to another reviewer's review.
- Students' slides are starting to look the same.
  See [Where to draw the line](../guide/limits.md#sameness).
