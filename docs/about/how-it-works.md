# How recipes work

## Sections of a recipe

| Section | Content |
|---|---|
| Summary | The recipe in two or three sentences. |
| Steps | Numbered steps to follow. |
| How to check the output | Who or what checks the result, and how long it takes. |
| Examples | Examples from groups that use the recipe, with names and details removed. |
| Known problems | Errors seen so far, linked to [What went wrong](../recipes/failures.md). |
| Skills | Skills for the recipe, from the [list of skills](../skills.md). |
| Related practices | The practices on [aiforscience.eu](https://aiforscience.eu) that the recipe follows. |
| Change history | Dated changes, newest first. |

The box "About this recipe" shows the research stage, how the output is checked (machine-checkable, expert-checkable or hard to verify), and how much freedom the agent has.

## Status

| Status | Meaning |
|---|---|
| <span class="afs-badge afs-badge--draft">draft</span> | Proposed, but not yet in regular use by the contributor. |
| <span class="afs-badge afs-badge--tried">tried</span> | In regular use by at least one group. |
| <span class="afs-badge afs-badge--reproduced">reproduced</span> | Used by a second, independent group, which added its own example to the page. |

A recipe becomes **reproduced** only when another group adds an example.
An error report can add a step to a recipe or change its status back.

## Review

Recipes and skills are reviewed in the same way as on [aiforscience.eu](https://aiforscience.eu).
Proposals and changes are public, editors review them, and every change is dated.
Names and details are removed from examples by default.
Contributors are named only if they ask to be.
