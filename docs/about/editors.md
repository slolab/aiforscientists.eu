# Editors and review

Input is open: anyone can add an example, report an error, share a skill or disagree with a recipe.
The editors decide what is merged.

## Editors

- Fabian J. Theis (Computational Health Center, Helmholtz Munich)
- Sebastian Lobentanzer (Computational Health Center, Helmholtz Munich)

## How changes happen

1. A change is proposed through an [issue template](https://github.com/slolab/aiforscientists.eu/issues/new/choose), a comment under a recipe, [Discussions](https://github.com/slolab/aiforscientists.eu/discussions), the [Google Group](https://groups.google.com/g/aiforscience), or a pull request.
2. An editor reviews it in the open, on the issue or pull request.
3. Merged changes appear on the site at once, with a dated line in the recipe's change history.

A recipe moves to **reproduced** only when a second, independent group has added an example.
An error report can add a step to a recipe or move its status back.

## Disagreement

If groups hold different positions on a recipe, the recipe records the positions and the conditions under which each holds.
How disagreement is expressed is covered by the [code of conduct](code-of-conduct.md).

## Join the editors

Editors from other institutes are welcome, in particular from wet-lab and clinical groups, which the first recipes cover least.
Make a contribution first, then say in [Discussions](https://github.com/slolab/aiforscientists.eu/discussions) or on the Google Group that you want to edit.
State which recipes you can cover and how much time you have.
