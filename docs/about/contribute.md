# Contribute

Anyone can contribute.

!!! note "Demo"
    The links on this page are placeholders.

## Ways to contribute

**Propose a recipe.** You give a task to an agent and the results hold up.
Describe the steps, how you check the output, and what went wrong.
<a class="afs-placeholder" href="#">Propose a recipe</a>

**Add an example to a recipe.** You used a recipe in your group.
An example from a second group changes a recipe's status from **tried** to **reproduced**.
<a class="afs-placeholder" href="#">Add an example</a>

**Contribute a skill.** You have a skill that others could use.
Remove internal paths, names, credentials and institute-specific forms, add a licence, and name the recipe it belongs to.
<a class="afs-placeholder" href="#">Submit a skill</a>

**Report an error.** An agent made an error that others should know about.
Names and details are removed by default.
<a class="afs-placeholder" href="#">Report an error</a>

**Disagree with a recipe.** A recipe does not work in your setting.
Say where and why.
<a class="afs-placeholder" href="#">Disagree with a recipe</a>

## Writing rules

- Short, plain sentences.
- Every result states the conditions under which it worked.
- Every recipe states how its output is checked.
- Names and details are removed from examples unless the contributor asks to be named.
- No advice on getting around institutional rules or model restrictions.

## What happens next

Editors review contributions in public, in the same way as on [aiforscience.eu](https://aiforscience.eu).
New recipes start as **draft**.
See [How recipes work](how-it-works.md) for the status levels.
