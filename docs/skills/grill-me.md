---
title: grill-me
skill: grill-me
status: brief
comments: true
recipe: 05-prototype-before-assigning
check_level: expert
does: Asks questions about a project description until its assumptions, data and success criteria are written down.
inputs:
- A draft project description.
outputs:
- A revised description with assumptions, data, success criteria and risks.
- The questions asked and the answers given.
steps:
- Read the description.
- Ask one question at a time about what is assumed, which data will be used, and what counts as success.
- Write down each answer.
- When nothing is left open, write the revised description.
local:
- Which data does your group have that a prototype could use?
- What does a student project description look like in your group?
never:
- Never decide whether the project is assigned; the group leader decides.
check: The group leader reads the revised description and decides whether to assign the project.
test: A project you already ran. Compare the open questions with what went wrong.
