# Code of conduct

AI for Scientists adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

The full text, and the spaces it applies in, are at
[aiforscientists.eu/about/code-of-conduct](https://aiforscientists.eu/about/code-of-conduct/).

Report unacceptable behaviour by writing to any of the editors named at
[aiforscientists.eu/about/editors](https://aiforscientists.eu/about/editors/).
